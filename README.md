# Цветочный мир

Статический каталог цветочного магазина: 37 товаров, поиск, фильтры, подробные карточки и информация о доставке по Москве. Данные каталога находятся в `js/app.js`; для каждой позиции есть отдельное изображение в `images/products/`.

Для локального запуска из корня проекта:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Для размещения на статическом хостинге загрузите содержимое этой папки без сборки. Сервер, база данных и внешние API сайту не нужны. Онлайн-заказ и оплата пока не предусмотрены.
